<h5 id="intro-ita"><strong>📚 Product Introduction</strong></h5>

<ul>
    <li id="bg-intro-ita"><p><strong>Background</strong></p>
      <p>Our client feels that the current manual handling of technical support tasks is inefficient. There is a need for integrated management of customer support responses and the provision of an optimized environment to improve user convenience. In addition, a platform that provides analysis tools for customer conversations would be highly desirable.</p>
    </li>
    <li id="goal-intro-ita"><p><strong>Goal</strong></p>
      Based on the background, we aim to build a solution that:
      <ul>
          <li>Delivers <u>instant, high-quality services</u> for various customer tech support operations.</li>
          <li><u>Learns from internal technical documents</u> and refer it as a guidance for query.</li>
          <li>Increases customer <u>convenience and transparancy</u> by allowing the download of relevant documents.</li>
          <li>Supports <u>multiple languages</u> to meet a wide range of customer needs.</li>
      </ul><br/>
      <p>Ultimately, the solution will reduce the workload on existing support teams. This will <u>lower holistic operational costs</u> by allowing support staff to be redeployed to more strategic tasks. Moreover, the solution will ensure high-quality and transparent services, ultimately established <u>stronger customer trust</u>.</p>
    </li>
    <li id="sol-intro-ita"><p><strong>Solutions</strong></p>
      <p>Our solution is divided into three modules: LLM-RAG Engine, Agent Personalization, and Monitoring Dashboard.</p>      
      <p>LLM-RAG Engine:</p>
      <ul>
        <li><u>Lightweight, powerful, and scalable</u> generative engine</li>
        <li><u>Enhances Agent knowledge</u> with internal docs through RAG.</li>
        <li><u>Supports 8 languages</u> for wide accessibility.</li>
      </ul><br/>
      <p>Agent Personalization:</p>
      <ul>
        <li><u>Persona:</u> Customize language, age, and interests for a relatable persona.</li>
        <li><u>Flow:</u> Set dialogue paths and default responses.</li>
        <li><u>Safeguard:</u> Content filtering, privacy settings, and escalation to human agents.</li>
        <li><u>Guidance:</u> Edit prompts and enhance user intent recognition.</li>
      </ul><br/>
      <p>Monitoring Dashboard:</p>
      <ul>
        <li><u>Manage knowledge database</u> effectively.</li>
        <li><u>Monitor and filter</u> user conversation streams.</li>
        <li><u>Track performance</u> and report conversation logs.</li>
      </ul><br/>

    <li id="3-key-ita">
      <p><strong>📈 Improved Scalability Concurrent User</strong></p>
      <strong>Problems</strong>
      <p>The initial infrastructure exhibited inconsistent performance under concurrent load. Due to limited hardware resources, the system could not reliably support a predictable number of users. Under stress, it frequently experienced latency spikes and even crashed.</p>
      <strong>Solutions</strong>
      <ul>
        <li>Develop a fallback mechanism to maintain smooth user experience.</li>
        <li>Re-architect the system to support a fallback mechanism and overall scalability.</li>
        <li>Optimize system components to improve overall performance.</li>
      </ul><br/>
      <strong>My Contributions</strong>
      <ul>
        <li>Implemented Dockerization for the AI Agent Engine to ensure efficient deployment and scalability.</li>
        <li>Engineered a cloud-based infrastructure to support scalability and ensure fallback mechanism integration.</li>
        <li>Refactored asynchronous code to eliminate thread blocking, significantly improving system concurrency and response times.</li>
      </ul><br/>
    </li>
    <li id="4-key-ita">
      <p><strong>📈 Improved Agent Issue Resolution Rate</strong></p>
      <strong>Problems</strong>
      <p>The initial version of the AI agent, alongside the early collection of documents registered in the vector database, was evaluated by the client’s internal tech support team and showed a low issue resolution rate.</p>
      <strong>Solutions</strong>
      <ul>
        <li>Curate and acquire high-quality knowledge to improve the relevance and coverage of the data in the system.</li>
        <li>Improve retrieval mechanisms by optimizing the vector database, ensuring faster and more accurate document matching.</li>
      </ul><br/>
      <strong>My Contributions</strong>
      <ul>
        <li>Conducted an investigation with the client to identify and select relevant knowledge sources.</li>
        <li>Developed a data sanitization pipeline to prevent information leakage and optimal knowledge content.</li>
        <li>Refactored the Chain-of-thought (CoT) pipeline to enhance processing speed and improve retrieval accuracy.</li>
      </ul><br/>
