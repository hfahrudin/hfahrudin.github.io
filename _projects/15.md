<p><strong>Orkes Watcher</strong> shows exactly what happened in every run of a graph-based agent: which nodes executed, which edges were traversed, how many times a loop re-entered, and what the state looked like at every step. It doesn't run your graph or wrap your logic in a new framework. Point an instrumented graph at a project's ingest endpoint, and every run becomes an inspectable, live-updating trace.</p>

<p><strong>🔹 Features</strong></p>
<ul>
<li><strong>Live trace inspector</strong>: a graph view of a run that updates node by node while it's still executing</li>
<li><strong>Dashboard</strong>: runs by outcome, p50/p95 run time, slowest nodes and top errors</li>
<li><strong>Project-scoped API keys</strong>: ingest or read-only, hashed at rest</li>
<li><strong>Role-based access</strong>: Admin, Developer and Viewer roles with per-project grants</li>
<li><strong>Retention and sampling</strong>: per-project limits on how long traces are kept</li>
<li><strong>Single-command deploy</strong>: self-host with one <code>docker compose up</code></li>
</ul>

<p><strong>🔹 Works with Orkes</strong></p>
<p>Attach a <code>WatcherSink</code> to an <a href="{{ 'projects/13' | relative_url }}">Orkes</a> graph (v0.1.4 or later) and traces are sent in the background. A watcher that's down never breaks your run.</p>

<pre><code class="language-python">from orkes.exporters.watcher import WatcherSink

sink = WatcherSink(api_key="&lt;project ingest key&gt;", base_url="http://localhost:8000")
graph = OrkesGraph(SearchState, name="search", trace_sinks=[sink])
</code></pre>
