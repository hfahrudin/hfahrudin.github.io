<p><strong>Orkes</strong> is a Python library for building, coordinating, and observing any workflow that can be represented as a graph. It is well suited for LLM-powered agentic systems, with a focus on explicit control flow, transparent logic, and full traceability. Its graph API is inspired by NetworkX and has no third-party dependencies.</p>

<pre><code class="language-bash">pip install orkes
</code></pre>

<p><strong>🔹 Core Concepts</strong></p>
<ul>
<li><strong>OrkesGraph</strong>: define a workflow as nodes and edges, where each node is a plain Python function</li>
<li><strong>Stateful execution</strong>: a shared state object flows between nodes during a run</li>
<li><strong>Traceability</strong>: every run produces a detailed execution trace you can inspect and visualize</li>
</ul>

<p><strong>🔹 Features</strong></p>
<ul>
<li><strong>Control flow</strong>: conditional branching, loops, parallel branches, and async runs with <code>arun</code></li>
<li><strong>LLM integrations</strong>: built-in support for OpenAI, Anthropic Claude, and Google Gemini, including tool calls and streaming</li>
<li><strong>Agents and tools</strong>: define custom tools and use them inside graph nodes</li>
<li><strong>Live observability</strong>: send traces to <a href="{{ 'projects/15' | relative_url }}">Orkes Watcher</a> with a <code>WatcherSink</code>, without changing your graph code</li>
</ul>

<p><strong>🔹 Benchmarks</strong></p>
<p>Compared with LangGraph on graphs with identical nodes and edges, Orkes runs up to 5x faster with up to 2x less memory on a 5-node graph, and up to 10x faster with up to 3x less memory on a 10-node graph.</p>
