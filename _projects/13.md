<p><strong>Orkes</strong> helps you coordinate LLM agents using plain Python. No magic, no unnecessary layers. Just explicit control flow, transparent agent logic, and simple message passing.</p>

<p>The goal of this effort is to make my trained model easily usable and inference-ready for anyone. I believe the potential applications of this work span across various domains, and I am excited to see how others might extend and build upon it.</p>

<p><strong>🔹 Core Principles</strong></p>
<ul>
<li><strong>Explicit control flow</strong> — use DAGs, FSMs, or plain loops</li>
<li><strong>Transparent agents</strong> — define prompt, tool, and logic directly</li>
<li><strong>Simple message passing</strong> — plain dicts, no graph state magic</li>
<li><strong>Minimal dependencies</strong> — only what you truly need</li>
<li><strong>100% Pythonic</strong> — easy to read, modify, and extend</li>
<li><strong>Stateless by default</strong> — you control memory and state</li>
<li><strong>Hackable and debuggable</strong> — nothing hidden</li>
</ul>
