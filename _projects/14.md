<p><strong>Automation Labs</strong> is a monorepo that brings my AI/ML projects and research implementations together using Git submodules. Each project is a practical, deployable application or a reproduction of a research idea.</p>

<p><strong>🤖 Agents</strong></p>
<ul>
<li><a href="https://github.com/hfahrudin/pawcha-agent" target="_blank" rel="noopener noreferrer">Pawcha</a>: a conversational agent that tracks and recalls your receipt-based purchases</li>
<li><a href="https://github.com/hfahrudin/fraud-chatbot" target="_blank" rel="noopener noreferrer">Nokcha</a>: an AI assistant that combines tabular data and documents into fraud insights</li>
</ul>

<p><strong>📊 AI/ML Pipelines</strong></p>
<ul>
<li><a href="https://github.com/hfahrudin/doc_dup_det" target="_blank" rel="noopener noreferrer">Doc Dup Det</a>: duplicate document detection with an embedding model and a vector DB</li>
<li><a href="https://github.com/hfahrudin/bb_vectordb" target="_blank" rel="noopener noreferrer">Barebone Vector DB</a>: a minimal vector database implementation</li>
<li><a href="https://github.com/hfahrudin/qlora_downstream" target="_blank" rel="noopener noreferrer">QLoRA Runner</a>: fine-tune, quantize, and evaluate LLMs for downstream tasks</li>
<li><a href="https://github.com/hfahrudin/ctlogs_stream" target="_blank" rel="noopener noreferrer">CTLogs Stream</a>: rate-limit-aware Certificate Transparency log ingestion with staggered workers</li>
<li><a href="https://github.com/hfahrudin/Dockerize-Llamafile" target="_blank" rel="noopener noreferrer">Dockerize Llamafile</a>: a containerized Llamafile that is easy to deploy and manage</li>
</ul>
