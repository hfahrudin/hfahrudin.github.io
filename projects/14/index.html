Automation Labs

A collection of deploy-ready AI/ML projects (agents, computer vision, ML pipelines) and research implementations.

Automation Labs is a monorepo that brings my AI/ML projects and research implementations together using Git submodules. Each project is a practical, deployable application or a reproduction of a research idea.

🤖 Agents

  • Pawcha: a conversational agent that tracks and recalls your receipt-based purchases
  • Nokcha: an AI assistant that combines tabular data and documents into fraud insights

📊 AI/ML Pipelines

  • Doc Dup Det: duplicate document detection with an embedding model and a vector DB
  • Barebone Vector DB: a minimal vector database implementation
  • QLoRA Runner: fine-tune, quantize, and evaluate LLMs for downstream tasks
  • CTLogs Stream: rate-limit-aware Certificate Transparency log ingestion with staggered workers
  • Dockerize Llamafile: a containerized Llamafile that is easy to deploy and manage

👁️ Computer Vision

  • Facex: a lightweight, high-performance facial expression classifier
  • Motion Nav: a motion-based presentation controller
  • Face Liveness Test: a webcam-based facial liveness authentication proof of concept

📖 Research Implementations

  • Meta-learning algorithms (MAML and Reptile)
  • Football defensive ghosting agent with imitation learning
  • T-Rex Run AI with deep reinforcement learning
  • VigenèreRSAImageLock: image encryption with Vigenère and RSA
